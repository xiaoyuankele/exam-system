# 后端开发

- 读取需求台账与对应功能技能。从本次必需的数据和接口开始。优先让真实请求走通，并保存后续复盘所需的数据。
- 在需求条目更新字段、错误和状态约定。按功能验证数据持久化，以及确实会遇到的失败、重试或重复提交。
- 将可联调入口、验证结果和剩余依赖回写对应需求。

- 对接软件内 Agent 时读取 [Agent 开发技能](../exam-agent-dev/SKILL.md)，在台账同步请求、输出和持久化边界。

## 交付时读代码

交付时读取 [代码导读](../exam-code-walkthrough/SKILL.md)，沿一次真实请求讲入口、关键业务逻辑和返回结果。接口效果不符合预期时，先记录输入、实际结果和期望结果，再调整并复验。
