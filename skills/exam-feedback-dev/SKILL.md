# AI 反馈与复测开发

- 将反馈关联到具体作答和题目版本，保留评阅依据。区分用户观察、AI 推断、AI 估评和可核实的评分结果。
- 复盘数据可表达猜对、辅助正确、超时和跳题。申论反馈可关联原稿和材料，缺少可核实评分依据时展示估评标记。
- 允许用户纠正 AI 的错因判断。评阅失败或重试时保留原始作答，避免重复计分。
- 支持从错因创建复测任务。统计时区分原题重做与独立新题，并展示可比的题量、正确数和用时口径。
- 验证一次作答能进入复盘，复盘能生成后续任务，完成复测后能查到对应的历史证据。
