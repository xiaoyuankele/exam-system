# 考公 Agent 开发

- 先和后端对齐一次业务调用的输入、输出、允许访问的数据和失败处理。首版使用 Python，在 FastAPI 后端内运行。用实际任务验证模型调用、结构化输出与失败恢复。
- 首个候选流程是用户交卷后，Agent 读取本次作答与题目依据，输出失分证据、待确认错因和复测建议。若具体步骤已经固定，按明确顺序执行。只有任务需要动态查取信息时才提供有限工具。
- 后端校验 Agent 输出并持久化最终状态。允许用户修正错因及采用建议。处理失败或重试时，保留原始作答，避免重复生成已采纳的任务。
- 验证一条正常作答、一条证据不足的作答以及一次模型失败。使用可重复的输入检查结论是否有据、输出是否符合合同、原始记录是否保留。

## 原理学习

围绕当前功能讲清 Python 如何接收输入和校验输出，以及 Agent 如何使用上下文、调用工具和返回结果。把每个概念对应到真实代码或最小示例。
