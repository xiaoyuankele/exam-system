# 前端开发

- 读取需求台账与对应功能技能。围绕本次用户操作实现最小页面和交互，明确加载、失败和完成时用户看到什么。
- 按双方共享的接口约定接入。后端还未就绪时可用符合约定的样例验证交互，交付时标明实际联调状态。
- 用软件真实入口检查目标操作，将接口缺口及验证结果回写对应需求。

## 交付时读代码

交付时读取 [代码导读](../exam-code-walkthrough/SKILL.md)，沿一个用户动作讲页面入口、状态变化和结果。遇到溢出或重叠时，按实际内容与窗口宽度复现，修复后检查原场景和常用宽度。
